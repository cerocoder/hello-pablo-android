**Требования:** R01, R02, R03, R04, R05, R06, R06.1, R07, R08, R08.1, R05i, R06i, G01, G02

**Status:** ready

## Что должно заработать

Нативное Android-приложение на Kotlin с Jetpack Compose: один экран,
показывающий ровно текст `"Hello Pablo"`. Никакой навигации, никакого
ввода, никакого состояния — один статический композабл.

Приложение собирается **не на этой машине**, а полностью на облачных
раннерах GitHub Actions: push в репозиторий
`git@github.com:cerocoder/hello-pablo-android.git` (SSH-ключ уже
настроен на этой машине, `~/.ssh/github_key`, использовать
`GIT_SSH_COMMAND="ssh -i ~/.ssh/github_key -o IdentitiesOnly=yes"`)
запускает workflow, который:

1. Собирает debug-APK (`./gradlew assembleDebug`) и кладёт его как
   артефакт джоба (`actions/upload-artifact`).
2. Поднимает Android-эмулятор на раннере через
   `reactivecircus/android-emulator-runner` и прогоняет инструментальный
   тест, который **реально проверяет**, что текст `"Hello Pablo"` виден на
   экране (не просто «приложение запустилось» — конкретный assert на
   текст).
3. Сохраняет полный `logcat` за время работы эмулятора как отдельный
   артефакт джоба — это доказательство именно **отладочной**
   возможности (доступ к реальным логам устройства), отдельно от факта
   эмуляции.

Довести CI до зелёного статуса — часть тикета, не «сдал и надейся».
Итог тикета: пуш в `kotlin-native/` на `main`, зелёный run в GitHub
Actions с тремя артефактами (APK, тестовый отчёт, logcat), ссылка на run
записана в `interfaces.md`.

## Критерии приёмки

- [ ] `kotlin-native/` — валидный Gradle-проект (Kotlin + Jetpack Compose), собирается `./gradlew assembleDebug` без ошибок
- [ ] Экран показывает ровно текст `"Hello Pablo"` (без опечаток, без обрезки)
- [ ] `.github/workflows/kotlin-build.yml` триггерится на push/PR с `paths: ['kotlin-native/**']`, чтобы не гонять сборку Flutter-модуля
- [ ] Workflow собирает debug APK и кладёт его артефактом джоба
- [ ] Инструментальный тест на эмуляторе (`reactivecircus/android-emulator-runner`) реально ассертит видимость текста `"Hello Pablo"`, а не факт запуска
- [ ] Полный `logcat` эмулятора сохранён отдельным артефактом джоба
- [ ] CI зелёный на реальном пуше в `github.com/cerocoder/hello-pablo-android` (не только локально валидный YAML)
- [ ] В `interfaces.md`, в раздел «Что заполнено тикетами», добавлена ссылка на зелёный run, имена артефактов, любые снэги/версии, которые пригодятся отчёту (тикет 03)
- [ ] Если после разумных попыток (несколько итераций правки workflow) CI не зеленеет по причине вне контроля (квоты, недоступность раннера) — тикет возвращается `BLOCKED` с точным логом ошибки, а не подменяется локальной сборкой
