## Что должно заработать

Flutter-приложение: один `StatelessWidget`, `Scaffold` с `Text('Hello
Pablo')`. Никакой навигации, никакого ввода, никакого состояния.

Собирается **не на этой машине** — полностью на облачных раннерах GitHub
Actions. Push в `kotlin-native/`-соседнюю папку `flutter/` того же
репозитория (`git@github.com:cerocoder/hello-pablo-android.git`,
SSH-ключ `~/.ssh/github_key` уже настроен, использовать
`GIT_SSH_COMMAND="ssh -i ~/.ssh/github_key -o IdentitiesOnly=yes"`)
запускает свой workflow, который:

1. Собирает debug-APK (`flutter build apk --debug`) и кладёт его
   артефактом джоба.
2. Поднимает Android-эмулятор на раннере (тот же
   `reactivecircus/android-emulator-runner`, что и в тикете 01 — единый
   подход для сравнимости отчёта) и прогоняет `integration_test`,
   который **реально проверяет**, что текст `"Hello Pablo"` виден на
   экране.
3. Сохраняет полный `logcat` за время работы эмулятора отдельным
   артефактом — доказательство отладочной возможности, отдельно от
   факта эмуляции.

Довести CI до зелёного статуса — часть тикета. Итог: пуш в `flutter/` на
`main`, зелёный run в GitHub Actions с тремя артефактами (APK, тестовый
отчёт, logcat), ссылка на run записана в `interfaces.md`.

## Критерии приёмки

- [ ] `flutter/` — валидный Flutter-проект (стабильный канал), собирается `flutter build apk --debug` без ошибок
- [ ] Экран показывает ровно текст `"Hello Pablo"` (без опечаток, без обрезки)
- [ ] `.github/workflows/flutter-build.yml` триггерится на push/PR с `paths: ['flutter/**']`, чтобы не гонять сборку Kotlin-модуля
- [ ] Workflow собирает debug APK и кладёт его артефактом джоба
- [ ] `integration_test` на эмуляторе (`reactivecircus/android-emulator-runner`) реально ассертит видимость текста `"Hello Pablo"`, а не факт запуска
- [ ] Полный `logcat` эмулятора сохранён отдельным артефактом джоба
- [ ] CI зелёный на реальном пуше в `github.com/cerocoder/hello-pablo-android` (не только локально валидный YAML)
- [ ] В `interfaces.md`, в раздел «Что заполнено тикетами», добавлена ссылка на зелёный run, имена артефактов, любые снэги/версии, которые пригодятся отчёту (тикет 03)
- [ ] Если после разумных попыток CI не зеленеет по причине вне контроля — тикет возвращается `BLOCKED` с точным логом ошибки, а не подменяется локальной сборкой
