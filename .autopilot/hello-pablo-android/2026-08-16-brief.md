# Тестовое приложение для Android

## Рекомендуемая технология

Порекомендуй три или две технологии создании приложений для Android.

Все они должны использовать внешние (не локальные инструменты), бесплатно.

При необходимости допустимо размещение кода приложения на github.com.

## Демонстрационное приложение

Используя каждую из рекомендованных технлогий создай приложение "Hello Pablo", которое:

- может быть загружено в телефон как apk;

- будет выводить текст "Hello Pablo";
